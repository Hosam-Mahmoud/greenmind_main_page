How It Works

1

Measure

Ultrasonic sensors measure the fill level of bins in real time with high accuracy.

2

Send

Data is sent securely via NodeMCU to our cloud API and database for processing.

3

Act

Dashboard updates bin status and triggers alerts when bins reach capacity.
